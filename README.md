# Smoking Detection — CNN Multi-Model Study

Image classification to detect smoking behavior using three deep learning approaches.

## Models
| Notebook | Model | Notes |
|---|---|---|
| `smoker_classification_mobilenetv2.ipynb` | MobileNetV2 | Transfer learning baseline, edge-deployable |
| `smoking_detection_efficientnetb3.ipynb` | EfficientNetB3 | Higher accuracy, fine-tuned |
| `smoking_detection_online_learning.ipynb` | River (online ML) | Incremental learning for streaming inference |

## Tech Stack
Python · PyTorch / TensorFlow · River · OpenCV · scikit-learn · matplotlib
